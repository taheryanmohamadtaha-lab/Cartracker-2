# سرویس خودرو (ردیاب مصرف سوخت و هزینه خودرو)

اپلیکیشن اندروید فارسی (Kotlin + Jetpack Compose) برای ثبت سوخت‌گیری، سرویس‌ها و هزینه‌های خودرو. کاملاً آفلاین.

سازنده: محمدطاها طاهریان

وضعیت: **مرحله ۴ از ۸** (ماژول خودرو، سوخت‌گیری و مصرف، سرویس‌های دوره‌ای با سررسید، تعویض قطعات، بیمه، معاینه فنی و سایر هزینه‌ها، عکس فاکتور)

## ساخت APK بدون اندروید استودیو
1. یک مخزن خصوصی در github.com بسازید.
2. محتویات این پوشه (شامل پوشه مخفی `.github`) را با Add file ← Upload files بارگذاری کنید. اگر `.github` بالا نرفت، فایل `.github/workflows/build.yml` را با Add file ← Create new file بسازید و محتوا را بچسبانید.
3. تب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد از تیک سبز، از پایین صفحه اجرا، بخش **Artifacts** فایل `CarTracker-debug-apk` را دانلود کنید و `app-debug.apk` را روی گوشی نصب کنید (اجازه نصب از منابع ناشناس).

راهنمای کامل: `راهنمای-مبتدی.md`
